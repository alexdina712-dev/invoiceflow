## Fixes and regression evidence

Login and account deletion consistently enforce bcrypt's 72 UTF-8 byte boundary. Parser errors carry no-store headers. A deterministic 500-case integer-cent oracle additionally checks fractional quantities, tax and discount rounding.

The password/request tests were run before the fix and reproduced the failures; the same tests passed afterward.

Vitest was updated to patched version 4.1.11. Prisma configuration dependencies effect and deepmerge-ts are pinned to patched versions 3.20.0 and 8.0.0 through pnpm overrides; Prisma validation and the complete suites passed.
The relevant upstream advisories are [Vitest](https://github.com/advisories/GHSA-82fw-gwwq-j7x9), [Effect](https://github.com/advisories/GHSA-38f7-945m-qr2g) and [deepmerge-ts](https://github.com/advisories/GHSA-ggr8-5vv4-36mx).

## Coverage and limits

The workflows exercise authentication/privacy, main create/edit/delete or status transitions, filtering, downloads and responsive navigation as applicable. InvoiceFlow tests verify real Unicode PDFs, 100-line pagination, authorization and totals. DataForge tests cover malformed files, macro/formula rejection, revisions, undo, exports and resource boundaries. CareerLens exercises real PDF/DOCX/TXT extraction and advisory analysis. OpsBoard exercises tenant permissions, project/task changes, comments and organization onboarding.

This is a reproducible portfolio QA pass, not a guarantee of no defects or an independent penetration test. Chromium device emulation does not establish Safari/Firefox compatibility or full accessibility compliance. Docker execution remains unverified where Docker is unavailable. Free hosting may sleep; no paid upgrade or artificial keepalive was introduced. Dependency scans are point-in-time checks.

## Reproduce

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm test:e2e
pnpm audit
```

Start the local PostgreSQL demo or supply DATABASE_URL and apply migrations before API tests. Test fixtures are fictional; never point database tests at a production database.
